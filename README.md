# who's that pokemon

a guessing game where players identify pokemon from their silhouettes.

## game mechanics

### objective
guess the pokemon's name by filling in the letter slots.

### gameplay
- a pokemon silhouette is displayed
- letter slots are provided for each character in the pokemon's name
- players have 5 attempts to guess correctly
- each incorrect attempt reveals a hint

### hints (progressive)
1. **first wrong attempt**: pokemon's generation
2. **second wrong attempt**: pokemon's type(s)
3. **third wrong attempt**: pokemon's description
4. **fourth wrong attempt**: 2 letters revealed in the answer slots

### game over
- win: correctly guess the pokemon's name
- lose: exhaust all 5 attempts
